# تم — ابدأ هنا كوكيل جديد

هذا مدخل موحد لأي مزوّد. لا يلزم أن تعرف محادثات الفريق السابقة.
المشرف يرسل لك بطاقة مهمة مكتملة؛ لا تختَر مهمة أو تحجزها بنفسك.

## تجهيز الوصول قبل الكتابة

يحدد المشرف: معرّف المهمة، الدور، SHA الأساس الكامل، الفرع، checkout
المستقل، ومسار البطاقة. إذا كنت محليًا، لا تعمل في checkout المشرف أو
checkout وكيل آخر. إذا كنت بعيدًا تحتاج المستودع بصلاحية مناسبة أو نسخة
محددة الهوية تتضمن التعليمات والكود والصور؛ المسار على جهاز المستخدم
لا يوفر وصولًا تلقائيًا. لا تضع بيانات اعتماد في المحادثة أو الملفات.

قبل الكتابة تحقق من `git status` وSHA الفعلي واسم الفرع، وقارنها بالبطاقة.
لا تبدّل فرع checkout مشترك ولا تحذف تعديلات موجودة لتصحيح الاختلاف.
الفرع الافتراضي main ليس بالضرورة أساس هذه الدفعة؛ اتبع SHA البطاقة.

المراجع تحدد التصميم الموجود، والبطاقة تحدد النطاق المعتمد. وجود صورة
لا يضيف الميزة كلها إلى تكليفك. البراند تم بدل مشوار، والثيم المركزي
هو مرجع الألوان والخطوط والمكونات. لا تنقل صفحات السائق لتطبيق العميل.

## رسالة الاستلام التي تعيدها للمشرف

```text
Task / role:
Actual baseline SHA / branch / isolated checkout:
Rules and task card read:
Owned / excluded paths:
Reference images actually viewed (UI IDs and filenames):
My understanding of the required behavior and acceptance criteria:
Shared interfaces / data mode / API handoff deliverables:
Missing inputs or decisions / unavailable tools:
Readiness: ORIENTATION_ONLY | READY_TO_IMPLEMENT
```

يستخدم `READY_TO_IMPLEMENT` فقط عند تطابق النسخة والبطاقة وتكليف المشرف
بمهمة READY وانتقالها إلى IMPLEMENTING باسمه. لا يحول الوكيل المهمة
المحجوبة إلى جاهزة بنفسه. إذا كانت البطاقة أو الأساس غير متاحين، يقرأ
السياق ويرسل النواقص دون تعديل التطبيق؛ عدم رؤية الصور يمنع العمل
التصميمي المعتمد عليها، ولا يمنع قراءة القواعد والكود المتاح.

## رسالة افتتاحية جاهزة يرسلها المستخدم

```text
أنت وكيل جديد في مشروع Tam | تم، وهذه جلسة استقبال وقراءة فقط الآن.
افتح المستودع/النسخة التي وفرتها لك، واقرأ
docs/engineering/agent-onboarding.md واتبع ترتيب القراءة فيه.
راجع لوحة المهام وفهرس الصور وافتح صور الميزة التي سأحددها لك.
أرسل تقرير الاستلام الموضح في ملف الاستقبال مع ما ينقصك.
لا تبدأ تعديل الكود أو إنشاء فرع تنفيذ قبل استلام بطاقة مسندة تتضمن
معرّف المهمة وSHA الأساس والفرع والملكية ومعايير القبول والمراجع.
لا تفترض أن main آخر نسخة أو أن عندك وصولًا لمحادثات الوكلاء الآخرين.
```

هذه الرسالة آمنة للاستقبال قبل اكتمال W1-BASE. عند اكتمال التجهيز يرسل
المشرف تكليف التنفيذ الفعلي بدل إبقاء الوكيل في دورة قراءة أو انتظار مبهمة.
حالة الوجود الفعلي للوكيل وتكليفه يسجلها المشرف بعد أن يخبره المستخدم،
ولا يُستنتج ذلك من إنشاء هذه الوثيقة.
