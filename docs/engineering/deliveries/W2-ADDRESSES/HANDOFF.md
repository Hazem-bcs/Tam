## السلوك والحدود

قائمة/تفاصيل/إضافة/تعديل/حذف مع تأكيد حذف وتجاهل تعديلات، واسم وأيقونات
home/work/study/gym/other، وموقع مختار من بحث الأماكن الموجود في Ride.
الاسم1..50 Unicode code points، والموقع label1..200 وإحداثياتGeoPoint صالحة.
القائمة bounded50 دونpagination فيv1؛ هذا استثناء موثق لمورد حساب صغير.
لا UI fixtures أو مفاتيحmock داخل Cubit/Page، ولا طبقات/use cases تمريرية.

TamApp يملك MockAddressesRepository واحدًا. يصل إليه دفتر العناوين
ومنتقي الحجز. تعديلات الجلسة تمسح عند الخروج، ويعود seed الاصطناعي فقط؛
لا حفظ دائم للمحاكاة أو ادعاء حفظ خادمي. يلغى stream مع المالك.
الإنشاء يحافظ على مفتاح العملية والجسم بعد رد مفقود، ويقفل تعديلها حتى
retry يحسم المحاولة نفسها. التعديل المطابق والحذف المتكرر آمنان.

Home/Settings تفتحان العناوين، وSettings تحافظ على حماية الدرفت غير
المحفوظ. منتقي الحجز يوفر بحثًا وعناوين محفوظة للانطلاق/الوجهة. يمرر
TripLocation snapshot إلى RideDraftBloc الموجود ويعيد التسعير عند تغييره؛
حذف العنوان لاحقًا لا يغير موقعًا مختارًا أو رحلة سابقة.

المواقع من RideAddressPlaceSearch data adapter فوق عقدRideRequestRepository؛
يترجم النتيجة للغة والأخطاء لحد العناوين، ولا يوجد مصدر أماكن آخر أو GPS.
GET /places يبقى عامًا مقترحًا وفق عقده الأصلي، وليس endpoint مملوكًا للعناوين.

ADDRESSES_DATA_MODE يرث DATA_MODE من AppConfig. مسارات /addresses و/new
و/:addressId/edit محمية فيapi؛ guest/localAccess لا يصبحان authenticated.
API غير جاهز يفشلSERVICE_UNAVAILABLE دونfallback، ولا ينشئHTTP أوcredentials.
تُحفظ هوية Cubit المحرر حسبid والمستودع لمنع عرض عنوان سابق عند تبديل المسار.

## تنظيم الكود وواجهة المرحلة الأولى

Domain وData وPresentation منفصلة؛ المستودعات تعيد domain وفشلًا واضحًا.
get_it يسجل factories، والتركيب يحقن الاعتماديات؛ لا locator أوI/O منwidget.
صفحات القائمة والمحرر مركزة تحت300 سطر، وكل ملفات المصدر الجديدة تحت300.
أضيف SettingsAccountLinks داخلSettings لإبقاء الصفحة مقروءة دون تجاوز300.
الترجمة عبر addresses ARB fragments والأداة نفسها؛ نواتجl10n ملتزمة للتكامل.

الثيم والتوكنز والمكونات المشتركة مستخدمة. التمرير يدعم صغر المساحة
والكيبورد وRTL/LTR والخط2x دونcap. منتقي الحجز صار سطح تمرير واحد حتى
تبقى عناصره قابلة للوصول فيlandscape معKeyboard؛ لا nested scrolling إجباري.
فروق الشكل النهائية (الخريطة الممتدة واللوحة السفلية والأصول) للمرحلةالثانية.
