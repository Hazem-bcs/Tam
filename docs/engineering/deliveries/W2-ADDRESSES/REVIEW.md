## نطاق الفحص والنتيجة

قُرئت AGENTS.md والبروتوكول وخطة العمل المتوازي وبطاقة المهمة والتسليم،
والاتفاق المعماري والثيم والتنقل وسياسة mock/API ومتطلبات حزمة الباكند
وخطة المرحلتين. فُحص التغيير كاملًا والملفات المجاورة المؤثرة، بما فيها
مصدر الأماكن وقواعد TripLocation/GeoPoint وRideDraftBloc ومسارات التطبيق.

لم يظهر عيب مانع ضمن النطاق. لا تحتاج نسخة الإنتاج إلى تصحيح في هذه
المراجعة. فصل Domain/Data/Presentation واضح، والاعتماديات محقونة والثيم
والتوكنز والترجمة مركزية. ملفات الميزة المكتوبة يدويًا مركزة دون تجاوز
إرشاد 300 سطر. لا fixtures أو اختيار وضع التشغيل داخل UI أو Cubit.

تحققت قواعد الاسم والموقع والحد العددي، والـcodec الصارم، وCRUD وتكرار
الإنشاء بعد فقد الرد وثبات مفتاح العملية والمدخلات، والحذف المتكرر.
مصدر العناوين واحد للجلسة ومشترك بين الإدارة والحجز، ويُصفّر عند الخروج.
اختيار الحجز يستخدم نسخة TripLocation مستقلة ويعيد التسعير؛ حذف عنوان
محفوظ لا يغير موقع المسودة المختار. تُلغى الاشتراكات والموارد عند إغلاقها.

تحققت حماية مسارات العناوين في وضع API للضيف وlocalAccess، وعدم إصدار
مصادقة أو fallback إلى mock. يبقى API غير المنفذ صريحًا في عدم توفره.
بحث الأماكن يعيد استخدام عقد Ride عبر adapter بيانات؛ لا GPS أو مزود جديد.

قُرئ العقد العربي وREADME وجميع أمثلة JSON وطلبات Collection واستجاباتها.
العمليات والترويسات والقيود والملكية وidempotency متسقة مع المحاكاة؛
القائمة المحدودة 50 دون pagination استثناء معلن. /places عام وفق عقده
الأصلي، و/addresses محمي. الأمثلة لا تحتوي أسرارًا أو بيانات إنتاج.
