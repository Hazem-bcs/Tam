## ما أصبح يعمل

- فوري/مجدولة ونافذة تاريخ/وقت؛ الإلغاء يحافظ على المسودة والسعر السابقين.
- حقول وقت24 ساعة من TamTextField وTamButton، بتمرير يدعم لوحة المفاتيح
  و2x، وتحقق hour0..23/minute0..59 وأرقام عربية/فارسية/لاتينية.
- اختيار الموعد أو تغييره أو مسحه يعيد التسعير لنفس المسار والفئة.
  quote مربوط بالموعد؛ لا يعاد استخدام سعر لموعد مختلف أو رد قديم متأخر.
- حدود الوقت تفحص في التسعير وعند الرد والتأكيد؛ مؤقت الانتهاء هو الأقرب
  من انتهاء quote وخروج الموعد عن الحد الأدنى. الأخطاء النهائية تفتح التعديل.
- المحاكاة تدعم SCHEDULE_UNAVAILABLE وSCHEDULE_OUT_OF_RANGE وحالات رفض
  التأكيد والتوفر المتغير. رد التأكيد المفقود يقفل التعديل ويعاد بنفس
  المفتاح والموعد، حتى إن انقضى الموعد بعد إنشاء الرحلة فعليًا في الذاكرة.
- TripBookingInput وRideQuote يحملان scheduledAt اختياريًا. المصدر نفسه
  ينشئ scheduled للمجدولة وrequested للفورية. active يشمل المجدولة،
  وتسميته العربية أصبحت «النشطة» لتشمل القادمة والجارية.
- القائمة والتفاصيل تعرضان الموعد مستقلًا عن تاريخ الإنشاء. الإلغاء يبقيه،
  وإعادة الطلب تنقل الموقعين فقط وتبدأ فورية بسعر جديد. الخروج يعزل الجلسات.

## البنية والمشاركة

لا Repository أو Draft موازيين. توسع عقد RideRequestRepository الموجود،
ومحاكاته المعزولة تستخدم MockTripStore المحقون. نفس RIDE_REQUEST_DATA_MODE
وحراسة الوصول؛ API غير الجاهز يفشل دون fallback أو توكن محلي.
لا تغيير في تسجيل الدخول أو OTP أو قواعد أرقام الهاتف أو الثيم الأساسي.

نُقل TripWireCodec إلى shared/data ليستعمله Ride وTrips لنفس المورد؛
أزيل parsing الرحلة المكرر من RideContractParser. UtcTimestamp صارم
للتاريخ التقويمي وUTC. نقل normalizeDigits نفسه من ملف الهاتف إلى shared/domain
مع import/export توافق فقط؛ لم تتغير خوارزمية الهاتف أو هوية Auth.
مصدر preview fonts للصور أصبح helper اختبار مشتركًا مع العناوين؛ لم يضف
خط إنتاج أو تحميل وقت تشغيل. تصوير W1-RIDE اختياري الآن بعلم CAPTURE_RIDE_GOLDENS
حتى لا تعيد الاختبارات العادية كتابة أدلة دفعة سابقة.

صفحة الحجز وأجزاء النافذة مركزة تحت300 سطر. استثناء موثق: RideDraftBloc
313 سطرًا لأنه يملك تسلسل المسودة/السعر/التأكيد ومؤقت الصلاحية وقفل العملية
نفسه؛ أبقيته متماسكًا بدل تقسيم الحالة الخاصة أو إضافة مدير تمريري.
لا ضغط تنسيق أو part أو منطق شبكة/جدولة تجارية في widgets.
