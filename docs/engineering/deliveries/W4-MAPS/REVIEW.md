## العيوب المثبتة والإصلاحات

**P2 — فقد وصف المستخدم أثناء انتظار GPS.** كانت locate تستدعي select بعد
رد المنصة، فتبدأ revision جديدًا وتمسح النص الذي كُتب أثناء الانتظار. صار
revision النص يبدأ مع طلب GPS ويستمر عبر reverse؛ الوصف الأحدث يبقى كما هو.
اختبار الارتداد فشل على المرشح ونجح بعد الإصلاح. تغطي الاختبارات أيضًا اختيار
نتيجة أثناء GPS، وطلب GPS بعد اختيار سابق، ودبوسًا أحدث ثم فشل GPS متأخرًا.

**P2 — نتائج بحث قديمة بعد اختيار Pin.** كان select لا يبطل طلب البحث السابق،
فتظهر قائمة لم تعد مرتبطة باختيار المستخدم. الاختبار أثبت الفشل؛ صار اختيار
الدبوس وبدء GPS يبطلان البحث السابق ويلغيان debounce ويمسحان النتائج. يبقى
البحث الجديد الذي يبدأ لاحقًا مستقلًا، وتحمي أجيال الطلبات الاختيار الأحدث.

**P2 — رمز 404 للمسار يخالف العقد.** كان HTTP adapter يعيد LOCATION_NOT_FOUND
لجميع القراءات، بما فيها POST /map/routes. صار يميز ROUTE_NOT_FOUND للمسار؛
اختبار HTTP يفحص الرمز نفسه لكل 404/422/429/503، ولا يكتفي بوجود exception.
نتيجة الارتداد قبل الإصلاح: 3 حالات فاشلة في
`/tmp/w4-review-regressions-before.log`؛ بعده نجحت الحالات المستهدفة.

أكملت إتاحة معلومات ترخيص OSM عبر رابط مستخدم صريح إلى صفحة copyright الثابتة،
بمحول Data قابل للحقن دون SDK في Widgets أو Domain. أُضيف target لا يقل عن48dp
وsemantics للرابط وفشل مترجم، مع أربعة اختبارات لعدم الفتح التلقائي والـURI
الثابت وفشل المنصة والضغط. لا يتصل هذا بمزود بلاطات/بحث عام، ولا يرسل موقعًا
أو Bearer. المرجع: [إرشادات OSM الرسمية](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)
و[معلومات الحقوق](https://www.openstreetmap.org/copyright).

وُثّق أن MAP_ALLOW_LOCAL_HTTP يرخّص عنوان loopback في تحقق Dart فقط؛ لا يضيف
استثناء Android cleartext أو iOS ATS. يستعمل اختبار الجهاز HTTPS موثوقًا.
لم أضف إعداد منصة واسعًا أو Podfile افتراضيًا؛ iOS يبقى تحققًا ساكنًا.

## نتيجة المراجعة المعمارية والسلوكية

- عنوانا البلاطات والخدمات اختياريان مستقلان وفارغان افتراضيًا. لا مضيف خدمة
  عامة أو fallback تشغيلي؛ عدم التهيئة ظاهر ويظل إدخال Pin ووصفه اليدوي ممكنًا.
  DATA_MODE لا يبدل الخرائط ولا يجعل localAccess/guest جلسة Backend.
- Domain لا يستورد SDK أو HTTP. Dio الخرائط مستقل عن عميل Auth، بلا Bearer
  أو cookies وبـredirects معطلة. عميل البلاطات يحصر origin ويحذف الاعتمادات
  ويمنع redirects، ويغلق موارده مع المزود؛ لا cache قرص دائم أو تنزيل مسبق.
- البحث مؤجل300ms، محدود100codepoints و20 نتيجة وباللغتين. reverse يحتفظ
  بنقطة المستخدم ويقبل النص فقط ضمن200م. الوصف اليدوي محدود200codepoints.
- codec يرفض envelopes/coordinates/geometry غير الصالحة؛ GeoJSON بترتيب
  longitude,latitude، LineString2..10000 نقطة، ووحدات صحيحة موجبة ومزود معروف.
  يتحقق من صدى الطرفين وقرب بدايات الهندسة، ولا يخترع خطًا مستقيمًا عند الفشل.
- المسار للعرض فقط ولا يثبت سعرًا أو حجزًا أو ETA من الهاتف. تغيّر الطرفين
  يبطل الطلب السابق؛ حركة السائق وحدها لا تعيد طلبه أو تفرض إعادة تحريك الكاميرا.
  ActiveTrip يخفي علامة الموقع القديم عند فقد حداثته.
- GPS قراءة foreground واحدة بطلب صريح، وفشل الإذن/تعطيل الموقع لا يمنع Pin.
  close والاختيارات الأحدث يبطلان الردود. أُضيف اختبار تطبيق فعلي للخروج أثناء
  انتظار GPS ثم الدخول بحساب محلي آخر: الصفحة تزول ولا تصل النقطة لمسودة جديدة.
  لا تغيير Auth أو TEMPORARY_PHONE_ENTRY أو عقود الحجز/المحاكاة السابقة.
- الواجهة تستهلك الثيم والتوكنز والترجمة المركزية وتبقي SafeArea والتمرير
  والكيبورد والخط الكبير. لا أعتبر Phase1 اعتمادًا بصريًا نهائيًا.
