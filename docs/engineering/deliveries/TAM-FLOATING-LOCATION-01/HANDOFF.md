# TAM-FLOATING-LOCATION-01

root، baseline `242cff7`، فرع `codex/customer-vector-maps-20261116`، دون وكلاء فرعيين.

بطاقات اختيار المشوار عائمة فوق الخريطة بهوامش جانبية وسفلية وحواف كاملة.
ارتفاعها يتبع المحتوى حتى الحد الأعلى، ثم يُمرر المحتوى؛ بطاقة اعتماد النقطة
مربوطة بالأسفل ولا تحجز مساحة بيضاء فارغة. يبقى سطح الخريطة mounted، ويُبلّغ
بارتفاع البطاقة الفعلي عبر notifier بدل إعادة إنشائه مع كل حركة.

احتُفظ بالمدخلات عند الطي عبر Visibility/OverflowBox. تبقى أهداف اللمس 48dp
والحركة ضمن مدد الثيم مع احترام reduced motion. قائمة المركبات تستخدم أربعة
SVG أصلية؛ اقتراحات الأماكن تستخدم قائمة بفواصل وعرض الاسم والمنطقة من النص
الموجود دون اختراع مسافات أو قرب من العميل. زر الخريطة بأيقونة أصلية ونص أوضح
يطوي بطاقة البحث لاختيار نقطة من الخريطة الخلفية مباشرة. بقي اختيار الخريطة
المستقل متاحًا عند استخدام RidePlacePicker خارج هذا التدفق.

لا تغييرات في Domain/Data أو الموقع أو Auth أو عقود API. الوضع المحاكى للحجز
وحدود خدمة المسارات غير المهيأة كما في التسليم السابق. RideJourneyShell مستخدم
أيضًا في خطوة البحث عن السائق، وتنتقل له هندسة البطاقة العائمة نفسها.

## التحقق المجمّع المحدود حسب طلب المستخدم

- تنسيق ملفات widgets المتأثرة، ومزامنة ARB ثم gen-l10n.
- `flutter test --no-pub test/features/ride_request/presentation/widgets/ride_map_journey_test.dart`:
  **7 ناجحة**، تشمل حفظ المدخلات عند الطي، استقلال GPS عن الاختيار اليدوي،
  الرجوع، والتحكم بالتمرير على 320dp مع خط كبير. استُخدم فحص محدد لأن تغيير
  قيود الارتفاع يمس إتاحة الأزرار ودورة حياة النموذج؛ لم تُكرر المجموعة الشاملة.
- بناء Android x64 `gradlew --offline ... app:assembleDebug` نجح؛ البناء النهائي
  في **6 ثوان**، `/tmp/tam-floating-final-build.log`. لا اعتماديات جديدة أو تنزيلات.
- مراجعة عربية فعلية على المحاكي القائم 1080×2400: البطاقة العائمة، قائمة
  الأماكن، رموز المركبات، الطي المباشر من زر الخريطة واعتماد النقطة دون فراغ سفلي.
  [الأماكن](screenshots/places.png)، [المركبات](screenshots/vehicles.png)،
  [النقطة المختارة](screenshots/map-point.png).
- أُجّل التحليل الشامل والمجموعة الكاملة ومصفوفة أحجام/لغات المعاينة إلى نقطة
  تجميع الميزات، حسب تفضيل المستخدم. لم يُدعَ اعتماد بصري نهائي أو release readiness.
