# W1-BASE — تسليم أساس الوكلاء الخمسة

المالك: المشرف. مرجع النسخة: Git tag `tam-w1-baseline-2026-11-07`؛
SHA الدقيق في رسالة الإرسال وتاريخ Git، دون مرجع ذاتي داخل محتوى الكوميت.

## النتيجة

اختيار mock/API مركزي لكل ميزة، ونقاط دخول ومسارات مستقلة، وحراسة api
للدخول الموثق، ونماذج رحلة مشتركة وMockTripStore واحد للحجز وطلباتي،
مع seed اصطناعي وضبط idempotency/cancellation ومسح عند انتهاء الجلسة.
AppLocaleController يغير لغة التطبيق دون إعادة إنشاء الراوتر. fragments
ARB مملوكة لكل ميزة تجمع إلى نفس مدخلات Flutter l10n عبر أداة تحقق.
أُعدت بطاقات A–E مع الملكية والمراجع والتكليف بالـcommit/push لفرعها فقط.

الأجسام الجديدة تعرض عدم توفر الميزة بصدق حتى يستبدلها أصحابها؛ هذا
ليس تنفيذًا نهائيًا للميزات الخمس. Auth والدخول المؤقت دون OTP محفوظان.

## أدلة التحقق المحلي

- `dart format --output=none --set-exit-if-changed lib test`: التنسيق ناجح.
- `flutter analyze --no-pub`: بلا ملاحظات.
- `flutter test --no-pub`: 136 اختبارًا ناجحًا، منها 11 للأساس الجديد.
- أداة جمع ARB: نجح الجمع وcheck؛ رُفضت لغة ناقصة وnamespace خاطئ وقيمة
  غير نصية وmetadata بلا نص وJSON duplicate، وبقيت المخرجات السابقة عند الفشل.
- لقطة route-boundary-ar.png فُحصت بصريًا باستخدام Flutter widget renderer
  بحجم 390×844 وخط Noto Sans Arabic من النظام للمراجعة فقط؛ ليس أصلًا
  مضافًا للتطبيق ولا تأكيدًا لشكل الخط على أجهزة Android/iOS.
- اختبارات Auth المشتركة تتحقق الآن من الحالة والرقم والتنقّل والخروج
  بدل نص رسالة Home المؤقتة؛ لم تُحذف اختبارات السلوك أو فحوص الأمان.

لا تشغيل لمحاكي أو Android build أو خدمة API حية. هذه أدلة تنفيذ محلي
لأساس المشرف، وليست مراجعة مستقلة أو اعتمادًا لميزات لم تُنفذ بعد.
كل ميزة تحتاج تسليمها ومراجعة SHA مستقلة وفحص التكامل.
