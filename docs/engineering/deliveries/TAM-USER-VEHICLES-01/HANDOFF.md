# TAM-USER-VEHICLES-01

root، baseline d40bcb4 مع معاينة السيارة السابقة؛ الفرع الحالي للخرائط.
استبدال صور الفئات الأربع برسومات المستخدم المحددة في assets/maps/README.md.
السيارتان والفان من الملفات الشفافة الأصلية، وخلفية الموتور أزيلت عبر imagegen.
النسخ الأصلية في Downloads محفوظة. أصول PNG داخل المشروع وليست روابط خارجية؛
عرض متناسب مع cacheWidth 320، وأيقونات إجراءات الخريطة تبقى SVG.

بناء Android محلي --offline وتثبيت ناجح على المحاكي القائم؛ مراجعة عربية فعلية
للأربع وشفافيتها في [الصورة](android.png). لم تُشغّل اختبارات أو تحليل شامل
لهذا الاستبدال البصري بحسب طلب المستخدم. لم تتغير العقود أو السلوك أو Auth.
لا push ولا merge إلى main. تبقى حدود mock والخدمات في التسليم السابق سارية.
