## الطلب والنطاق

طلب العميل تجهيز الموقع عند دخول التطبيق ومزامنته إذا تحرك خلال الجلسة،
مع أولوية موثوقية البيانات. الملكية: maps، وصلات جلسة التطبيق وAppConfig،
الانطلاق التلقائي ومراجعة الحجز والترجمات والفحوص ذات الصلة. التعليمات
المعتمدة: AGENTS.md، agent-task-template، working-agreement، ADR البنية،
نظام التصميم وخطة المرحلتين. الأدوات والكود متاحان؛ لا تغيير في Auth أو
صلاحيات API أو الثيم أو بقية تصميم الشاشات. لا backend endpoint جديد.

## السلوك المسلم

- مصدر ForegroundLocation واحد للجلسة يُحقن في المستهلكين؛ يبدأ بعد دخول
  guest/localAccess/authenticated. لا يبدأ جمع الموقع من شاشة تسجيل الدخول.
- متابعة حركة منخفضة التواتر أثناء ظهور التطبيق، مع وقت القياس ودقته،
  ورفض القديم والمستقبلي وغير الدقيق وخارج الترتيب. القراءة الأحدث الضعيفة
  تبطل الكاش السابق. الساعة monotonic تمنع تمديد صلاحية الكاش بمجرد
  تعديل الساعة الجدارية. لا اعتماد على آخر موقع محفوظ لجلسة سابقة.
- فحص إذن/خدمة الجهاز قبل استخدام الكاش، ودمج طلبات القراءة المتزامنة.
  إيقاف الاشتراكات وإبطال الكاش عند paused/hidden، وإعادة تجهيز الموقع عند
  العودة دون عرض إذن النظام تلقائيًا. inactive العابر لا يوقف حوار الإذن.
- إبطال النتائج عند الخروج أو تبديل الجلسة، مع رفض أي نتيجة قديمة متأخرة.
  لا permission خلفية جديدة أو تخزين دائم أو رفع مسار حركة للخادم.
- قراءة عالية الدقة جديدة تتجاوز الكاش قبل حجز بانطلاق تلقائي. العمر
  المقبول حينها 5 ثوانٍ، مقابل 20 ثانية للكاش العادي، والدقة المُبلّغ عنها
  حتى 50 مترًا والمهلة 15 ثانية. هذه حدود قبول قابلة للضبط مركزيًا، لا
  ضمان فيزيائي لدقة GPS أو لزمن وصول النظام.
- تحرك أكثر من 50 مترًا يعيد الانطلاق والتسعير ومرحلة المراجعة دون إرسال
  حجز. التذبذب الأصغر يبقي نقطة الانطلاق التي راجعها المستخدم. اليدوي
  والعناوين المحفوظة وإعادة الحجز لا تُستبدل بتحديث تلقائي. مصدر الانطلاق
  محفوظ صراحة في حالة المسودة، وليس باستنتاج النص أو تساوي الإحداثيات.
- نتيجة تأكيد غير محسومة يعاد طلبها بنيتها ومفتاحها السابقين؛ لا تغيير
  انطلاق أو إعادة تسعير أثناء retry حتى لا يتكرر الحجز.
- تعذر التحقق ظاهر داخل خطوة التأكيد، مع retry أو اختيار يدوي. تجهيز
  الموقع لا يمنع متابعة تحديد الأماكن يدويًا أثناء انتظار القراءة.

DeviceLocation يدعم requireFresh؛ LocationSensor يعزل SDK؛ LocationFix
وLocationPolicy ومالك الجلسة لا تستورد Flutter أو منصة. الإعدادات في
AppConfig. صفحة الحجز 305 أسطر؛ التجاوز البسيط لدليل 300 يبقي callbacks
والتنقل وامتلاك Cubit متماسكة بدل استخراج wrapper بلا مسؤولية مستقلة.
