# TAM-LOCATION-DESIGN-02 — تسليم معاينة التصميم

الأساس107497f، الفرعcodex/ride-location-design-20261116. تنفيذ root وفق تكليف المستخدم واعتماده للتصور المولد. لا تغيير Auth أو البيانات الخلفية أو رسوم العربات.

- ثلاث مراحل قرار مسماة: المكان، المركبة، التأكيد؛ البحث عن السائق حالة مستقلة بعد الإرسال، والسلوك الداخلي محفوظ.
- بطاقة النقطة بحجم المحتوى، بلا إحداثيات أو حقل فارغ دائم؛ اختيار الوجهة/الانطلاق يغير إجراء اعتماد واحدًا. الوصف الاختياري يستخدم label الموجود في TripLocation؛ لم نضف حقل API غير مدعوم.
- دبوس متجه مرسوم داخل Flutter وظل من الثيم، بلا تنزيل صورة. يرتفع عند السحب مع احترام reduced motion. يقع طرفه عند مركز كاميرا الخريطة المبطنة لتجنب البطاقة. تتحدث النقطة عند idle فقط، وطلب العنوان يبقى في RideLocationCubit مع إبطال النتائج القديمة.
- طي البطاقة عند تحريك الخريطة، وإعادة فتحها باللمس أو السحب؛ الأدوات تحتفظ بالحد الأدنى لمساحة اللمس. زر رجوع أخف، موقع حالي دائري، وحذف +/- من المتجهة وfallback النقطية.
- اللغة والثيم مركزيان. أسماء المراحل تختصر في المساحة الضيقة دون تعطيل text scaling.

## التحقق الفعلي

- مزامنة ARB وgen-l10n، وتنسيق الملفات المعدلة، وgit diff --check.
- 10 اختبارات محددة ناجحة: ride_map_journey_test.dart وnative_vector_map_test.dart. شملت اختيار يدوي مع GPS متأخر، حفظ الوصف عند الطي، الرجوع، إعادة التحقق من الانطلاق، 320dp ونص2x، وانتقال النقطة أثناء pan مرة واحدة عند idle دون إعادة تمركز متكررة.
- عولج تجاوز عرض أسماء المراحل أثناء الفحص، وحدّث الاختبار فتح الوصف واختيار الدور. الفحص الناجح سبق تعديل مظهر المقبض والطي التلقائي؛ جرى التحقق من الطي وإعادة الفتح يدويًا على Android بعد آخر تعديل.
- آخر Android offline assembleDebug ناجح في6ثوان، ثم install-r وتشغيل على emulator-5554 الموجود. لم تنزل حزم أو emulator.
- [لقطة Android فعلية](android.png): اختيرت نقطة، سُحبت الخريطة، طويت البطاقة تلقائيًا وأعيد فتحها. ترك التطبيق في هذه الحالة للمستخدم؛ لا طلب حقيقي.

لم نشغل المجموعة الكاملة أو analyze، ولم نجر مراجعة فعلية جديدة للتابلت/الإنجليزية/لوحة المفاتيح؛ مؤجلة وفق تفضيل تجميع الفحوص. خدمة العناوين/الطرق غير مهيأة في هذه المعاينة: النقطة الفعلية محفوظة والعنوان عام بصدق. لا اعتماد بصري نهائي؛ المستخدم سيقيّم النتيجة.

NativeVectorMap يتجاوز إرشاد300سطر لأنه يحافظ على دورة حياة واحدة مترابطة للمحرك الأصلي والكاميرا والتزامن؛ رسم المؤشر وأدوات التحكم منفصلان. لا push أو دمج main أو Actions ضمن هذه المهمة.
