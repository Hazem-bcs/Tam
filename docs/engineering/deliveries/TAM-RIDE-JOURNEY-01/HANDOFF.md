# TAM — معاينة تصميم رحلة الحجز

**مراجعة لاحقة:** استُبدلت ألوان الحجز والخلفية ومدخل الخطوة الأولى
بتوجيه المستخدم؛ الحالة الأحدث موثقة في [TAM-RIDE-ENTRY-02](../TAM-RIDE-ENTRY-02/HANDOFF.md).
المحتوى والصور أدناه يوثقان معاينة النسخة السابقة.

التاريخ: 2026-11-13. الفرع `codex/tam-home-rebuild-20261112`.

وسّع المستخدم نطاق المهمة صراحة من الرئيسية إلى تجربة الحجز المتتابعة،
مع تقديم نجاح التصميم والفحص على المحاكي على تكرار حزمة الاختبارات.
المصدر البصري: ملفه المحلي TAM_Motion_Prototype_v1.html والصور الخمس
لاتجاه Urban Pulse. الألوان والخطوط في الثيم المركزي فقط.

## النتيجة

زر «مشوار» يفتح الآن رحلة متتابعة بدل النموذج الطويل:
1. مدخل الرحلة.
2. الانطلاق ثم الوجهة، مع البحث والعناوين المحفوظة واختيار الخريطة.
3. عادية / مريحة / فان / موتور، مع الفوري والجدولة.
4. المراجعة والسعر والمدة والمسافة والفئة والدفع من عرض السعر الحالي.
5. البحث عن السائق بعد نجاح تأكيد الطلب في مستودع المحاكاة الحالي.

لوحة واحدة يتغير ارتفاعها ومحتواها، مع بقاء السياق البصري، ورجوع يحفظ
المسودة. لا توجد أحداث نجاح مصطنعة أو تأكيد بتأخير داخل الواجهة.
مرحلة البحث تستمد حالتها من ActiveTripCubit وتنتقل عند تحديث الحالة
الموجودة؛ لا تملك الواجهة مؤقت تعيين سائق. الإلغاء والدعم والتفاصيل باقية.

المخطط الخلفي مصرح بأنه توضيحي عند غياب الخرائط الخاصة؛ النقاط والعناوين
من المسودة، والوصلة تخطيطية وليست مسار ملاحة. عند تهيئة الخرائط الخاصة
يستخدم RouteMapView الموجود. لا مزود خرائط عام أو مواقع/أسعار داخل UI.

## التغييرات

- RideRequestPage أصبحت منسق عرض للخطوات مع حالة محلية مؤقتة فقط.
- مكونات ride_journey_* للوحة والخلفية والمدخل وتكوين كل خطوة.
- RidePlacePicker يدعم الإدراج داخل اللوحة مع بقاء استعماله القديم كنافذة.
- فئات المركبات والجدولة والمراجعة تعيد استخدام البلوك والعقود الموجودة.
- ActiveSearchJourney يمثل حالة requested الموجودة في الرحلة الجارية.
- AppColors.urban وAppTheme.rideJourney يضبطان كل الألوان والضوابط والخط
  دون تغيير Auth أو إعدادات التطبيق أو عقود Domain/Data/API.
- نصوص AR/EN ضمن ARB الميزة ومخرجات التوليد الحالية.

## التحقق وحدوده

شُغّل Android debug على Medium_Phone الموجود، وجُرّب المسار فعليًا:
المزة / شارع الجلاء ← أبو رمانة / شارع الحمراء ← مريحة ← المراجعة
← تأكيد المحاكاة ← البحث عن السائق. الصور من Android نفسه.
الفحص الساكن والتنسيق موثقان في تسليم التنفيذ. لم تُعد الحزمة الكاملة
بعد إعادة تكوين الحجز، استجابة لتوجيه المستخدم بأولوية التصميم الآن.
نتيجة 689 السابقة تخص الرئيسية قبل توسيع نطاق الحجز، ولا تعتمد هذا التدفق.
اختبارات UI القديمة التي تفترض نموذج الحجز المسطح تحتاج مواءمة بعد اعتماد
التصميم؛ لم تُحذف أو تُعطّل. لا ادعاء 60fps أو جاهزية إصدار أو اعتماد مستقل.

الحالة: DESIGN_PREVIEW. يلي قبول الشكل مواءمة اختبارات التدفق، مراجعة
أحجام الخط والمقاسات للتدفق الجديد، وتوسيع الهوية لبقية حالات الرحلة الجارية.
لا push أو main أو Actions. الباكند والخرائط الحية غير موصولين.
