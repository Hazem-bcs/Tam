# TAM-PLACE-PICKER-03 — اختيار الموقع المبسط

Root implementation/supervisor، أساس9403d95، فرعcodex/ride-location-design-20261116. نفذ التصور الأول المعتمد بعد طلب حذف إدارة العناوين.

النتيجة: عنوان واحد «إلى أين؟» أو «من أين؟»، مع سياق الطرف الآخر القابل للتعديل. حقل البحث وإجراء خريطة خفيف بلا بطاقة شرح. المحفوظات تظهر تلقائيًا كبطاقات عرضية، وتتحول إلى ترتيب عمودي على العرض الضيق أو النص الكبير. لا إدارة عناوين أو تبويبات أو اقتراحات عامة عند الدخول. أثناء الكتابة تظهر نتائج الاستعلام فقط، ومسحه يعيد المحفوظات مع الاحتفاظ بمصدرها المحمل. اختيار العنوان ينتقل وفق التدفق القائم دون زر متابعة إضافي. إعادة اختيار الطرف نفسه تعالج صراحةً حتى لا يعلق المستخدم بانتظار تغير بيانات لم يحدث.

الحدود: يعرض SavedAddressPicker الموجود عبر خيار compact؛ شكل الإدارة الافتراضي خارج الرحلة محفوظ. بيانات العناوين من المستودع المحقون وليست بيانات مزروعة في الواجهة. لم نغير العقود أو fixtures أو اختيار mock/API أو Auth أو الخريطة. أوقف RideDraftBloc الطلب الفارغ وأبطل نتيجته السابقة لمنع اقتراحات قديمة عند مسح البحث. لا صلاحيات أو اعتماديات جديدة. في هذه المعاينة العناوين والبحث من mock المأذون المركزي، وليست نتائج خدمة أماكن حية.

التحقق المنفذ:
- تسعة اختبارات ride_map_journey_test.dart ناجحة، مع تحديث توقع عنواني الشاشة الجديدة؛ تشمل الطي والرجوع والاختيار و320dp ونص2x.
- ثلاثة اختبارات ride_place_picker_test.dart ناجحة: لا طلب فارغ، تجاهل نتيجة متأخرة بعد المسح، تبديل المحفوظات/نتائج البحث، العودة للمحفوظات واختيار إحداثيتها، العربية والإنجليزية بعرض320dp ونص2x وkeyboard inset260. أصلحنا توقع اختبار يبحث عن العنوان الكامل رغم عرضه مقسمًا؛ ونقلنا إغلاق المستودع إلى teardown لتجنب انتظار إغلاق stream داخل fake async. لم نخفِ فشلًا في التطبيق.
- dart format للملفات المعدلة، sync_feature_l10n.py --check، gen-l10n، git diff --check.
- بناء Android offline للمعاينة المنفصلة locationpreview ناجح30ثانية، وتثبيتها على emulator-5554 الموجود. راجعنا البحث مع لوحة المفاتيح، ثم [شاشة المحفوظات الفعلية](android-saved-first.png) بالعربية1080×2400. توجد عمليات أخرى تغير الواجهة الأمامية على المحاكي؛ فتحنا حزمة المعاينة المحددة دون استبدال حزم الآخرين. لم ننزل حزمًا أو محاكيًا.

الفحوص الشاملة وanalyze والتابلت/الإنجليزية الفعلية/profile مؤجلة وفق تفضيل التجميع؛ الفحص الإنجليزي أعلاه Widget وليس جهازًا فعليًا. الرسم الجديد ليس اعتمادًا بصريًا نهائيًا؛ المستخدم يقيّمه. RideDraftBloc والصفحة الموجودان يتجاوزان300سطر أصلًا، أبقينا التنسيق وحدود المسؤولية وأضفنا فقط قواعد المسح/اختيار الطرف نفسه؛ فصلت ورقة الاختيار وبطاقات العناوين بملفين مركزين. لا push أو دمج main أو Actions لهذه المتابعة.
