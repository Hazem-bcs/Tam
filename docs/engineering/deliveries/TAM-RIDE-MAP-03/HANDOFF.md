## الطلب والملكية

توسيع التفاعل ضمن الخطوات الخمس فقط: تقليل اللوغو وإزالة AppBar الكبير،
تصميم أفضل للتقدم، لوحة قابلة للطي لتوسيع الخريطة، النقر لتحديد الانطلاق
أو الوجهة، إذن/تفعيل GPS عند الدخول والانطلاق التلقائي، وحركة خفيفة.
ثم صحح المستخدم المقاسات أثناء التنفيذ: طلب لوحة أصغر وخطًا وأيقونات
أهدأ وطابعًا أقل ضخامة. الصورة المرجعية الأخيرة:
/tmp/codex-clipboard-c7f2c2a3-7d4e-4091-b8f5-289f1f766e12.png.

استمرار بنفس التعليمات والمراجع المعمارية والتكليف السابق. الملكية تشمل
واجهات ride_request وحالة requested في active_trip، وصلات maps اللازمة
لهما، إعدادات الثيم المركزية للرحلة، والترجمات والاختبارات المعنية. لا عمل
متوازٍ أو ملفات متنافسة. أدوات Flutter/Android والصور متاحة. لا تعديل Auth
أو نشر أو push أو main أو Actions، ولا حزم أو خدمة خارجية جديدة.

## ما تغير

- أزيل AppBar من الحجز والبحث؛ رأس عائم صغير مع لوغو أخف واسم المرحلة
  وخمس علامات، ورقم المرحلة متاح لوصول الشاشة وTooltip.
- اللوحة تنطوي بزر أو بسحب المقبض، مع استعادة التفاصيل باللمس أو السحب.
  تبقى حالة الحقول، وصف نقطة الخريطة ونص البحث عند الطي، وتُوقف tickers
  للمحتوى المخفي. عند ظهور لوحة المفاتيح يُراعى ارتفاع العرض الجديد.
- مدخل الحجز يستهدف حوالي 286dp في حجم النص المعتاد، ويزيد مع النص
  الكبير أو إشعار الموقع. ليس نصف شاشة ثابتًا. خط الرحلة المركزي أصبح
  أدق وأقل سماكة، الحقول بيضاء بخط حدود هادئ، والزر أصغر بصريًا مع
  مناطق لمس لا تقل عن 48dp. فئات المركبات والبحث والمراجعة والمطابقة
  تستخدم هذا الثيم نفسه. ألوان البرجندي والأبيض باقية.
- الخريطة تبقى مركبة أثناء الطي والانتقال الداخلي. تحريك اللوحة يحدّث
  مواضع الضوابط ونسبة المصدر فقط عبر ValueListenable وAnimatedBuilder؛
  لا يعيد بناء FlutterMap في كل tick. الضوابط تختصر إلى الموقع في مساحة
  الخريطة الصغيرة، وتعود أزرار التكبير عند توسعتها. pinch/pan باقٍ.
- نقر الخريطة يظهر نقطة مؤقتة ووصفًا اختياريًا وخيارَي الانطلاق/الوجهة.
  لا إرسال حجز من النقر، ولا اعتماد إحداثية مختلفة أو عنوان تجريبي.
- الدخول للحجز يطلب قراءة foreground واحدة عند عدم وجود pickup مسبق،
  ويعرض إذن Android إن لم يُمنح. التعطيل له طلب واضح بفتح إعدادات الموقع؛
  الرفض الدائم له إعدادات التطبيق. الرفض العادي/التعذر يتيحان المحاولة
  والاختيار اليدوي. زر الموقع يتيح إعادة التحديد صراحة.
- الرجوع من الإعدادات يعيد تحديد الموقع مرة واحدة، ولا polling أو تتبع
  مستمر. اختيار pickup يدوي يلغي اعتماد GPS المتأخر. Cubit scoped للصفحة
  ويرفض النتائج بعد close. GPS لا يستبدل prefill قائمًا.
- انتقالات fade/slide قصيرة وارتفاع لوحة متحرك وتفاعل اختيار المركبة؛
  جميعها تحترم disableAnimations. الانتقال الخارجي للحجز والمطابقة فقط
  يستخدم CustomTransitionPage. بقية التطبيق خارج إعادة التصميم.

## الحدود والبيانات

OSM العام يظل مصدر raster مؤقتًا مع caching ومعرّف التطبيق ونسبة دائمة.
لا geocoding عام. عند غياب reverse API، يحتفظ الاختيار بالإحداثيات
الدقيقة ووصف المستخدم أو تسمية عامة، ويظهر GPS باسم «موقعي الحالي».
تختلف جودة raster حسب التكبير والكثافة وسرعة تحميل الصور؛ لم نغيّر مصدره
إلى ناقل vector أو نضف شوارع/مسارات مزيفة. سعر/رحلة الحجز ما زالا mock.
لم يُنشأ endpoint أو عقد backend جديد؛ maps-v1 السابق دون تغيير.
التحكم بإذن وإعدادات الهاتف محلي عبر منفذ Domain ومحول Geolocator.
