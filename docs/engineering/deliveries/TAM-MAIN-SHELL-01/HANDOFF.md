## النتيجة

- `app/shell/MainShell` يملك Scaffold وشريطًا واحدًا، ويستقبل `StatefulNavigationShell`.
- `app/router/main_shell_route.dart` يركب ثلاث StatefulShellBranch تحت
  `StatefulShellRoute.indexedStack`: الرئيسية `/`، نشاطي `/trips`، حسابي `/settings`.
  تُحمّل الفروع عند الحاجة، ويحافظ الراوتر على Navigator وحالة كل فرع؛ لا Cubit عام أو بيانات مكررة.
- أُزيلت أشرطة التنقّل من Home وTrips وSettings، وحُذف المكونان القديمان.
  `CustomerNavigation.openTrips/openSettings` يبدلان الوجهة بـgo بدل push.
- شريط موحد بثلاثة أقسام متساوية، الأيقونة فوق النص ومحاذاة مركزية مستقرة، وتحديد برجندي
  من ColorScheme. يستخدم textTheme وAppTokens، تسميات ARB المشتركة، Semantics وتحديد التبويب
  وإجراء tap، وحركة قصيرة تحترم reduced motion. ينمو مع حجم الخط بدل قصه أو تحديد مقياسه.
- لا تعيد ضغطة التبويب الحالي إنشاء الصفحة. التبديل يخفي لوحة المفاتيح ويحفظ المسودة.
- الرجوع من التبويبات الثانوية يعود للرئيسية. حسابي يستقبل onBack صريحًا من تركيب التطبيق
  لحفظ المسودة؛ بقي تحذير فقدان التعديلات للصفحات المنفصلة وتسجيل الخروج وروابط الحساب.
- صفحات التفاصيل والحجز تفتح على Navigator الجذري فوق Shell؛ الرجوع يستعيد التبويب السابق.
- انتهاء الجلسة يزيل الفروع وحالاتها. لم تتغير Auth أو قواعد الوصول أو Domain/Data أو API
  أو إعدادات الخرائط أو أنماط mock/API. لا يُعامل الضيف أو localAccess كمستخدم باك موثق.
