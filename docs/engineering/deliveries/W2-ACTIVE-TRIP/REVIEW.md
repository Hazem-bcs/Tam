  وlive ذري بإصدار متوقع، ولا تُستبدل هوية الحجز أو قيمته أثناء تقدم المحاكاة.

  سائق أو الوصول أو بدء/إنهاء الرحلة. تُستدرك المجدولة عند موعدها والزمن
  المنقضي، ويستمر المحرك عند مغادرة الصفحة وينظف موارده عند التخلص منه.

  سباقات القراءة والإلغاء وفقد الرد وإعادة الإلغاء للمعرف نفسه، وتناسق
  الإلغاء من طلباتي، وتمييز noDriver النهائية وإعادة التسعير لطلب جديد.
- Cubit يحمي هوية snapshot وإصداراتها، ويحتفظ بآخر حالة عند الانقطاع؛

  الاشتراكات والمؤقتات تغلق، وعزل الخروج ومسح بيانات الجلسة مختبران.
- الحقن والمسارات والسياسات مركزية. ACTIVE_TRIP_DATA_MODE يرث DATA_MODE؛
  API غير الجاهز يفشل دون fallback، ومساراته تمنع guest/localAccess مستقلًا
  عن وضع طلباتي. لم يتغير Auth أو TEMPORARY_PHONE_ENTRY.
- قُرئت حزمة `docs/api/active_trip/`: العقد العربي v1 وREADME، أمثلة النجاح
