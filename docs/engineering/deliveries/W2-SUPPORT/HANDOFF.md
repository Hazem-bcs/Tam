## السلوك

دعم عام من Settings وبلاغ رحلة من ActiveTrip/Trips/Completion؛ يتحقق المستودع
من الرحلة في المخزن المشترك. فئات من catalog، نص10..2000 code points بعد
trim، إرسال بمعرف عشوائي ثابت عبر retry، منع التكرار وidempotency conflict.
عند فقد الرد يقفل النص والفئة حتى retry بنفس النية. قائمة20 مع cursor
وتفاصيل للقراءة، وحالات open/in_progress/resolved مصدرها المستودع.
المحاكاة تبدأ فارغة والجديد open، دون ادعاء موظف أو SLA أو جهة اتصال حقيقية.

المقبول يبقى داخل جلسة المستودع ويُمسح عند الخروج. الاستجابات المتأخرة لا
تستعيد جلسة قديمة؛ تغيّر نص/فئة/رحلة/معرف إنشاء مورد معروف يُرفض، وكذلك
تغير snapshot بنفس revision؛ الإصدارات القديمة لا تستبدل الأحدث.
كل ملفات الميزة أقل من300 سطر، بلا fixture في widgets أو mode switch.

الشروط والخصوصية صفحتان عامتان للقراءة؛ تعرضان أن المحتوى غير منشور حتى
تسليم النص المعتمد، ولا تنشئان إقرار موافقة. فشلAPI منفصل عنunpublished.
SUPPORT_DATA_MODE مستقل، وAPI غير جاهز يفشل SERVICE_UNAVAILABLE دون fallback.
حراسة tickets لا تمنح localAccess/guest مصادقة. الثيم/ARB/التوكنز موحدة.

[حزمة الباكند](../../../api/support/README.ar.md): عقد عربيv1، Postman2.1
بسبعة طلبات وsaved responses، وأمثلة مطابقة للمحاكاة والـmapper، بما فيها
25 طلبًا عبر صفحتين والحالات والأخطاء والقانوني null. لا HTTP adapter بعد.
