## السيناريو المعتمد للتنفيذ

| الحالة | الأداء | الانتقال |
|---|---|---|
| Welcome | يد مريحة، الأخرى تحيي مرتين بحركة قصيرة متأخرة عند المعصم | مرة واحدة، ثم Idle |
| Idle | كفان مرتاحان بأصابع منحنية قليلًا؛ تنفس وكتفان ومعصمان بحركة هادئة غير متناظرة؛ تعديل صغير عابر | دورة طويلة متصلة دون قفزة في النهاية |
| Focus | اليدان أقرب قليلًا للجسم بوضعية انتباه؛ تنفس صغير؛ العينان تتبعان المؤشر | blend نحو 250–350ms |
| Waiting | وضعية ترقب هادئة، حركة معصم بسيطة دون تلويح متكرر | طوال waiting، ثم الحالة الفعلية |
| Error / Sad | هبوط الكتفين واليدين والتفاف الكفين للداخل، بالتزامن مع الوجه الحزين | دخول قصير ثم تنفس |
| Recovery | ارتفاع هادئ وارتخاء الكفين باتجاه Focus أو Idle | نحو 300–450ms بلا إعادة Welcome |
| Success / Happy | ارتفاع خفيف للجسم، فتح الكفين ورفعهما وارتداد قصير ثم استقرار | صلاحية إدخال الهاتف محليًا أو نجاح فعلي، دون تأخير التنقل |
| Reduced motion | وضعية ثابتة تعكس الحالة؛ إيقاف الحلقة المستمرة والإيماءات الواسعة | تتحدث الوضعية عند تغيير الحالة |
| Hidden / Background | لا تشغيل للحركة أو مؤقتات مستمرة | استئناف آمن عند العودة |

الأولوية: success > error > waiting > focus > idle؛ otpStage سياق لا يتجاوز
الخطأ. مدخلات Flutter الحالية: phoneFocused, waiting, hasError, otpStage,
success, gazeX, gazeY. صلاحية الهاتف تستخدم normalizeSyrianPhone الحالية، ولا تعني تحقق ملكية الرقم
أو مصادقة باكند؛ لا تظهر الفرحة مع busy أو failure. لا نحتفظ بتحدٍّ منتهي
ولا نؤخر التنقل لإكمال الحركة. لا تغيير لقواعد Auth أو الراوتر أو الدخول المؤقت/الضيف.
