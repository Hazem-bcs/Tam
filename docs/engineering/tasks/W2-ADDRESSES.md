## قرارات العقد

GET/POST /addresses، GET/PATCH/DELETE /addresses/{id}. القائمة كاملة محدودة
بـ50 عنوانًا للحساب دون pagination فيv1؛ هذا استثناء موثق لمورد صغير محدود.
النموذج: id,name,icon,location(label,latitude,longitude),created_at,updated_at.
الاسم1..50 Unicode code points بعدtrim؛ location.label1..200؛ أيقونات
home/work/study/gym/other. إحداثيات WGS84 صالحة وفقGeoPoint المشترك.
GET /places معاد الاستخدام من عقدride_request؛ اختيار موقع يتطلب نتيجة
بحث صالحة، ولا تكتب إحداثيات تقنية في نموذج المستخدم.
POST بمفتاح عملية ثابت لإعادة المحاولة، والتعديل استبدال الحقول القابلة
للتعديل نفسها، والحذف idempotent. تفاصيل HTTP/auth/errors في حزمةAPI.
البيانات المحاكاة لا تحفظ عبر إعادة التشغيل؛ تمسح التعديلات عند الخروج
ويعاد seed الاصطناعي فقط. لا Tokens أو هوية مصادقة جديدة.
