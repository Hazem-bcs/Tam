# تم — لوحة المهام المشتركة

آخر تحديث: 2026-11-07. يدير المشرف وحده التكليفات وتحديث هذه اللوحة،
وفق تقارير الوكلاء؛ لا تكتشف اللوحة نشاط محادثات Claude/Gemini وغيرها تلقائيًا.
لم يبدأ أي وكيل بهذه الدفعة بعد. [خطة الدفعة](wave-one-plan.md) مرجع النطاق.

## الحالات والحجز

- `PLANNED`: مقترحة وتحتاج تفاصيل/مدخلات قبل الإرسال.
- `BLOCKED`: المانع مذكور؛ عدم وجود مالك لا يجعلها متاحة.
- `READY`: بطاقة مكتملة وbaseline متاح، ولا يوجد تعارض ملكية؛ متاحة للتكليف.
- `IMPLEMENTING`: حجزها المشرف لوكيل بفرع وcheckout محددين قبل الكتابة.
- `REVIEW`: تسليم على SHA محدد، متاح لمراجع مستقل يكلفه المشرف.
- `APPROVED_AT_SHA`: اعتماد النسخة النهائية المحددة بعد الإصلاحات.
- `INTEGRATED`: دمج وفحص في فرع التكامل الموثق، وليس بالضرورة main.

عند تعثر مهمة جارية يسجل المشرف الحالة السابقة وسبب التوقف والملفات
التي تبقى محجوزة؛ لا يفسر BLOCKED كإخلاء للملكية أو إذن لوكيل ثان بالكتابة.
لا يختار الوكيل مهمة من نسخة قديمة ولا يحجزها تلقائيًا؛ يطلبها من المشرف.

## الأساس المشترك

الكود السابق محفوظ ومرفوع على `feat/auth-contract` عند
`90d2a600fead5d975369af31fed4e616984e715a`. يُحفظ تحديث خطة الفريق مع قواعد
Dart والمحاكاة في كوميت لاحق على الفرع نفسه؛ يتحقق المشرف من تطابقه
مع GitHub. ذلك يزامن خطة العمل، لكنه لا ينفذ إعداد mock/API في Dart.

قبل بدء كود الميزات، ينفذ المشرف W1-BASE ويحفظ أساس التنفيذ ويضع SHA
الكامل **نفسه** في بطاقات الخمسة. لا يبدأ أحد من main القديم أو من وصف
«آخر نسخة» وحده. إذا أضيف تغيير مشترك لاحقًا، يسجل SHA واعتماد المهام عليه.

## الدفعة الحالية — خمسة ملاك ميزات ومشرف

| المهمة | الحالة | المالك / المراجع | شرط الانتقال إلى READY |
|---|---|---|---|
| W1-BASE: تجهيز الأساس والعقود | PLANNED | المشرف / يحدد عند التسليم | تكليف التجهيز التالي، قبل إرسال تنفيذ الميزات |
| W1-HOME: الرئيسية | BLOCKED | غير مسند / عند التسليم | W1-BASE + مرجع ونطاق الرئيسية ونقاط الدخول |
| W1-RIDE: طلب الرحلة | BLOCKED | غير مسند / عند التسليم | W1-BASE + حالات الحجز والسعر والمحاكاة وحدود الموقع |
| W1-TRIPS: طلباتي | BLOCKED | غير مسند / عند التسليم | W1-BASE + تعريف الرحلة والحالات والإلغاء والترقيم |
| W1-NOTIFICATIONS: صندوق الإشعارات | BLOCKED | غير مسند / عند التسليم | W1-BASE + أنواع ووجهات الإشعارات والعداد |
| W1-SETTINGS: الإعدادات والحساب | BLOCKED | غير مسند / عند التسليم | W1-BASE + فصل المحلي/الخادمي وربط اللغة والخروج |
| AUTH-API: الربط الحقيقي | BLOCKED | غير مسند / غير مسند | جاهزية الباكند وتفويض المستخدم؛ ليس من ميزات الدفعة الخمس |

BLOCKED هنا بسبب تجهيز الأساس والمواصفات، وليس لأن الباكند غير جاهز؛
المستخدم أجاز المحاكاة. لا تُعلن خمس مهام READY قبل توافر شروطها فعلًا.
لكل ميزة ملكية محددة في الخطة، وتضاف بطاقة تفصيلية مستقلة عند التكليف.

## حفظ معرفات التخطيط السابق

المهام القديمة غير المسندة لم تبدأ ولم تُحذف نتائج منفذة:
TAM-001 (مواصفات Home) يُستوعب في تحضير W1-HOME، وTAM-002 (تدقيق Dart)
مؤجلة كتدقيق اختياري. TAM-003/004/006 تتوزع بين W1-HOME/W1-RIDE،
وTAM-005 يصبح AUTH-API، وTAM-007 ضمن W1-SETTINGS بنطاقه المحدد والعناوين
للاحق، وTAM-008 يصبح W1-TRIPS. لا نعيد استعمال الأرقام لمعان مختلفة.

يستخدم المشرف [قالب التكليف والتسليم](agent-task-template.md). عند نهاية
العمل يرسل الوكيل SHA واختباراته وعقد API وPostman وأدلته للمشرف عبر
المستخدم أو قناة مأذون بها؛ لا يعدل نسخًا متنافسة من اللوحة داخل فرعه.
المشرف يطلب المراجعة ويجمع المعتمد تدريجيًا. لا تبدأ مهمة جديدة بعد التسليم
إلا بتكليف آخر، ولا يُستنتج إذن main/Actions من اعتماد كود الميزة.
