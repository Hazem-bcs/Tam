# ADR0004 — عارض خرائط العميل

قرار التنفيذ2026-11-10 بعد اعتماد المستخدم تجهيز جهة Flutter فقط دون
خدمات عامة؛ الخدمات الخاصة غير جاهزة. يتمم ADR0003 ولا يغير مسؤولية السعر.

flutter_map يعرض raster XYZ256 من عنواننا الصريح؛ البيانات والستايل من
بنيتنا مع نسبة OSM. لا Google Maps SDK أو public tile endpoint أو fallback.
تصل خدمات البحث والعكس ومعاينة الطريق عبر Laravel بصيغة موحدة. يظل
اختيارOSRM/Google واستضافة البحث والبلاطات على الخادم، لا فيUI/Bloc.

Repository/codec/HTTP وGPS فيmaps/data؛ Domain بلا SDK. MapScope يحقن
اعتماديات التطبيق المنشأة فيget_it؛ widgets لا تصل للـlocator. الموقع
foreground ضمن جلسة الاستخدام المأذون بها. AppConfig يملك العناوين والتحقق منHTTPS.
المسار المعروض GeoJSON موثوق بصحة حقوله وحدود حجمه وسياقه، وليس سعرًا.
لا رسم توضيحي بديل أو أثر booking حقيقي بالمحاكاة.

اختيار raster حد حالي معلن؛ استضافة vector tiles تتطلب عارضًا وعقد styles
مختلفين ولا تُفعّل بعنوانMVT في إعدادPNG. إعداداتنا فارغة حتى يوفرها الخادم.

المراجع الأولية: https://docs.fleaflet.dev/layers/raster-tile-layer.md
وhttps://pub.dev/documentation/geolocator/latest/ .


## تعديل مؤقت 2026-11-13 — معاينة الخريطة العامة

طلب المستخدم الآن خريطة OSM حقيقية مباشرة حتى تجهيز سيرفره. لهذا
يختار AppConfig البلاطات العامة افتراضيًا، مع بقاء override السيرفر الخاص
والتعطيل الصريح. لا fallback أو خدمة بحث/توجيه عامة مضافة.
OsmTileProvider يستخدم تخزين HTTP-aware دائمًا ومعرّف التطبيق، دون تنزيل
مسبق، وبقاء نسبة المصدر ثابتة فوق الخريطة. PrivateTileProvider يحتفظ
بسلوكه السابق عند ضبط العنوان الخاص. انظر README.ar.md في docs/api/maps
وتسليم TAM-RIDE-ENTRY-02 للمشاهد وحدود المعاينة.


تحديث 2026-11-15، بطلب المستخدم: ForegroundLocation يملك قراءة الجهاز
على مستوى جلسة التطبيق، ويُحقن مصدر DeviceLocation نفسه لكل مستهلك عبر
MapsDependencies. يبدأ بعد دخول العميل، ويتابع الحركة بدقة متوسطة خلال
الاستخدام، ويوقف اشتراكاته ويبطل الكاش عند paused/hidden أو الخروج من
الجلسة. لا صلاحية تتبع خلفية أو persistence أو رفع موقع جديد للخادم.

LocationFix يحتفظ بوقت القياس والدقة في Domain؛ LocationPolicy ضمن
AppConfig يحدد عمر الكاش والدقة والمهلة والمسافة. يتجاوز التحقق قبل الحجز
الكاش بطلب جديد، ويعيد المراجعة والتسعير عند تحرك انطلاق GPS. حالة المسودة
تحفظ مصدر الانطلاق صراحة، فلا تُعامل النقطة اليدوية كموقع تلقائي حتى لو
تطابقت الإحداثيات. رد التأكيد غير المحسوم يعاد بنفس النية دون تغيير نقطة
الانطلاق. التحديد اليدوي يسبق أي نتيجة متأخرة، ولا تتجاوز النتائج حدود
الجلسة أو lifecycle. التفاصيل والحدود في docs/api/maps/README.ar.md.
