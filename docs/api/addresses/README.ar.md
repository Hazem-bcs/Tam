# حزمة العناوين المحفوظة — لمطور الباكند

اقرأ [العقد](addresses-v1.md)، ثم استورد
`addresses-v1.postman_collection.json` كـCollection v2.1.
هذه مواصفات مقترحة لما نحتاجه، وليست وثائق لخادم قائم.

1. غيّر `base_url` إلى عنوان Laravel ويشمل `/api/v1`.
2. ضع `access_token` حقيقيًا وفق عقد Auth؛ الدخول المحلي والضيف ليسا مصادقة API.
3. ابدأ بقائمة العناوين، ثم تفاصيل عنوان، ثم الحفظ والتعديل والحذف.
4. غيّر `address_id` إلى المعرف الراجع من الحفظ.
5. استخدم `operation_id` جديدًا لكل إضافة مقصودة، واحتفظ به وبالجسم
   عند إعادة المحاولة بعد فقد الرد؛ لا تغير المفتاح لكل retry.
6. راجع Saved responses للنجاح والفراغ والتحقق والملكية والحد والتعارض والفشل.
7. بحث الأماكن يعيد استخدام عقد `ride_request`؛ لا API جديد لمزود خرائط آخر.

النطاق: قائمة محدودة50 عنوانًا، تفاصيل، حفظ اسم وأيقونة وموقع، تعديل وحذف،
واختيار موقع محفوظ داخل الحجز. لا تطلب هذه الحزمة ترقية guest/localAccess
إلى authenticated أو إصدار tokens اصطناعية أو تشغيل GPS.

أمثلة `examples/` تطابق fixtures وparsing في Flutter، ومعرفاتها اصطناعية.
المحاكاة مؤقتة في ذاكرة الجلسة. التحسين البصري النهائي في المرحلة الثانية.
نتائج التحقق وحدوده تسجل في تسليم `W2-ADDRESSES`؛ صلاحية JSON أو فحص
schema لا تعني طلب خادم حيًا أو استيرادًا فعليًا داخل واجهة Postman.
لا تضمّن متغيرات حقيقية أو أسرارًا عند إرسال Collection.
