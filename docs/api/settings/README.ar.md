# تسليم إعدادات حساب العميل — Tam / تم (W1-SETTINGS)

**الإصدار:** settings-v1، حالة العقد: **مقترح للتنفيذ**. لا توجد واجهات Settings متصلة بالخادم أو اختبار HTTP حي في هذه الدفعة.

## ما يحتاجه الباكند

تطبيق Flutter يقرأ الاسم/الصورة الاختيارية (للعرض فقط) وتفضيل إشعارات الحساب، ثم يعدّل الاسم أو التفضيل باستدعاءات منفصلة. لا يغيّر الهاتف أو الهوية أو جلسة Auth. جميع الواجهات الأربع محمية بتوكن جلسة **authenticated** حقيقي وفق عقد `docs/api/authentication-v1.md`؛ الدخول المؤقت/الضيف ليس مصادقة خادمية.

| تصرف العميل | Repository | الواجهة المطلوبة |
| --- | --- | --- |
| فتح الحساب | loadProfile | GET /me/profile |
| فتح الإعدادات | loadPreferences | GET /me/preferences |
| حفظ الاسم | updateDisplayName | PATCH /me/profile |
| حفظ الإشعارات | updatePreferences | PATCH /me/preferences |
| تغيير العربية/الإنجليزية | AppLocaleController.setLocale | **لا يوجد endpoint** |
| تسجيل الخروج | callback من Auth | خارج عقد Settings |

الهاتف `phoneE164` المحقون للعرض فقط؛ لا يُعاد من الواجهات المقترحة ولا ينفّذ تعديل رقم الهاتف. الصورة `avatar_url` تُعرض إن توفرت لاحقًا، لكنها حقل قراءة فقط الآن؛ لا يوجد رفع صور ولا SDK جديد. لا تُنشأ هنا محافظ أو عناوين أو بصمة أو تفضيلات الوضع الداكن أو حذف حساب أو SMS أو Push.

## Postman

استورد `settings-v1.postman_collection.json` (Collection v2.1). اضبط `base_url` مثل `https://api.example.com/api/v1` و`access_token` بتوكن اختبار مخوّل فقط؛ المتغير الافتراضي خالٍ بلا أسرار. رتّب الطلبات: GET profile/preferences، ثم PATCH profile/preferences، ثم GET للتأكد. توجد أمثلة saved responses للنجاح والـ401 والـ422 والـ503. ملفات `examples/` هي نفس بيانات الأمثلة ومعايير parsing المستخدمة بالـMock.

**لا تُنفّذ الطلبات على خادم إنتاج من دون مراجعة العقد والموافقة عليه.** فحص JSON والاستيراد الفعلي وHTTP الحي أشياء منفصلة تُسجّل نتائجها في HANDOFF.

## الفصل بين المؤقت والمحفوظ

- الوضع `mock`: مستودع ذاكرة ضمن التطبيق، لا ينشئ حسابًا، ولا يحدّث Auth أو الخادم؛ الحفظ يظل طوال عملية تشغيل التطبيق فقط.
- الوضع `api`: حاليًا يفشل بـ`SERVICE_UNAVAILABLE` بلا fallback إلى mock، حتى يحين تكامل HTTP المصرّح به.
- اللغة `ar/en`: إعداد محلي فوري عبر `AppLocaleController` أثناء تشغيل التطبيق الحالي؛ **الاستمرار بعد إعادة التشغيل غير مطلوب** ولا يُطلب حفظها على الخادم.
- مفتاح إشعارات الحساب: تفضيل مستقبلي وليس طلب إذن نظام ولا تفعيل Push/FCM.

راجع `settings-v1.md` لتفاصيل الحقول والـheaders والأخطاء والحدود، ومثال fixtures الاصطناعية. جميع البيانات الواردة في الأمثلة خيالية وليست بيانات مستخدمين.
