# ربط خرائط تم

العقد [maps-v1.md](maps-v1.md)، الأمثلة فيexamples/، وحزمة Postman مستقلة
ومضمنة أيضًا فيCollection العميل الموحدة.

تحديث 2026-11-13 بتوجيه المستخدم: البلاطات الافتراضية مؤقتًا من
`https://tile.openstreetmap.org/{z}/{x}/{y}.png` حتى تجهز الاستضافة الخاصة.
هذا اختيار صريح للمعاينة، وليس fallback عند فشل السيرفر الخاص.
تبقى خدمات البحث والعكس والمسار غير مهيأة دون `MAP_API_BASE_URL`.
لا يرسل التطبيق عنوان البحث أو توكنات الحساب إلى OSM؛ عارض البلاطات
يطلب الصور اللازمة للعرض فقط بمعرّف `TamCustomer/0.1 (com.tam.tam_customer)`،
وتخزين flutter_map المحلي يحترم HTTP caching headers وETag.
لا تنزيل مناطق أو prefetch. يظهر رابط `© OpenStreetMap contributors`
دائمًا على البلاطات العامة، وفق [سياسة المزوّد](https://operations.osmfoundation.org/policies/tiles/).

لاستبدال البلاطات بالسيرفر الخاص استخدم:

```bash
flutter run --no-pub -d emulator-5554 \
  --dart-define=MAP_TILES_URL_TEMPLATE=https://maps.your-domain/tiles/{z}/{x}/{y}.png \
  --dart-define=MAP_API_BASE_URL=https://api.your-domain/api/v1
```

استبدل النطاقين بعناوين خدماتنا الفعلية. DATA_MODE=mock يظل يحاكي الحجوزات؛
اختيار خدمات الخرائط مستقل وصريح. إعداد العناوين لا يحول mock booking
إلى طلب حقيقي، ولا يرقّي guest/localAccess إلى مصادقة API.

لإيقاف البلاطات صراحة استخدم `--dart-define=MAP_TILES_URL_TEMPLATE=`.
حينها يعمل العارض دون بلاطات، ويظهر عدم التهيئة.
يمكن الاختيار بالإحداثيات من اللوحة وتسميته يدويًا، ويُجهّز GPS عند دخول جلسة العميل، مع زر لإعادة التحديد داخل الحجز.
هذا ليس خريطة offline أو إثبات طريق حقيقي. يجب توفير الخدمة لتقييم التغطية.

اختبارات Flutter تستعمل HTTP adapter ومزود صور ذاكرة وGPS platform بديلًا؛
لا توكنات أو اتصالات بخدمات عامة في الاختبارات؛ يعطّل harness التكامل البلاطات ويترك حقن مزوّد الاختبار متاحًا. يلزم اختبار HTTPS وCORS للويب وAndroid/iOS
على الخدمات الفعلية عند تسليمها. لم تُنشر بنية خرائط أو بيانات منطقة هنا.

MAP_ALLOW_LOCAL_HTTP يرخّص فقط التحقق من عنوان loopback في إعدادات Dart؛
لا يفتح cleartext في Android ولا يستثني ATS في iOS. لا يوجد استثناء منصة
عام أوخاص في هذا التسليم؛ استخدم HTTPS موثوقًا حتى في اختبار الجهاز.

نسبة OSM تفتح https://www.openstreetmap.org/copyright عند ضغط المستخدم فقط،
عبر محول url_launcher؛ هذه صفحة معلومات ترخيص، وليست خدمة خرائط تشغيلية.
لا تُفتح تلقائيًا ولا يمرر إليها التطبيق إحداثيات أو توكنًا. فشل فتحها ظاهر.


## الموقع المشترك أثناء استخدام التطبيق — 2026-11-15

بناءً على طلب المستخدم، يبدأ تجهيز الموقع بعد دخول جلسة العميل (ضيف،
دخول محلي، أو حساب)، بدل انتظار شاشة التكسي. مصدر واحد يشارك قراءة
الجهاز بين الشاشات، ويتابع الحركة أثناء ظهور التطبيق فقط. يطلب إذن
الاستخدام عند الحاجة عند بدء الجلسة؛ العودة من الخلفية تتحقق من الإذن
والخدمة دون إعادة عرض إذن النظام تلقائيًا. تعطيل الخدمة أو سحب الإذن
لا يسمح باستخدام قراءة مخزنة بدل الفشل. الرفض لا يمنع الاختيار اليدوي.

السياسة المركزية AppConfig.locationPolicy: عمر التخزين المؤقت حتى 20 ثانية،
ودقة مُبلّغ عنها من الجهاز حتى 50 مترًا. تعتمد الصلاحية على وقت التقاط
القراءة وعمرها في ساعة monotonic محلية؛ ترفض القراءة المستقبلية، القديمة،
غير الدقيقة والمتأخرة عن قراءة أحدث. القراءة الأحدث ضعيفة الدقة تبطل
المخزون السابق. هذه حدود قبول وليست ضمانًا فيزيائيًا لدقة GPS.
تحديثات الاستخدام العادي تطلب دقة متوسطة ومسافة 20 مترًا وفاصل 10 ثوانٍ
على Android؛ تلك تفضيلات للنظام، وليست ضمانًا لمعدل وصول القراءات.

قبل إرسال حجز جديد بانطلاق تلقائي، تُطلب قراءة عالية الدقة تتجاوز الكاش،
بحد انتظار 15 ثانية وعمر أقصى 5 ثوانٍ. الحركة أكثر من 50 مترًا تعيد
اختيار الانطلاق والتسعير وتطلب مراجعة جديدة؛ لا إرسال صامتًا بموقع جديد.
الاختيار اليدوي والعناوين المحفوظة وإعادة حجز رحلة سابقة لا تُستبدل بـGPS.
إعادة محاولة طلب تأكيد ذي نتيجة غير معروفة تحتفظ بنيته ومفتاحه السابقين؛
لا تعيد اختيار الانطلاق أثناء تلك المحاولة.

الانتقال إلى paused/hidden يوقف اشتراكات الموقع ويبطل الكاش، والعودة
تجهز قراءة جديدة. inactive القصير (مثل حوار الإذن) لا يعادله. تسجيل
الخروج يمحو حالة الموقع؛ نتائج طلبات قديمة لا تعبر إلى الجلسة الجديدة.
لا صلاحية background جديدة أو تخزين دائم أو رفع سجل حركة للخادم. قد
تستكمل قراءة واحدة سبق طلبها حتى مهلة SDK، لكن نتيجتها تُرفض بعد مغادرة
التطبيق أو تبديل الجلسة. العقد maps-v1 وحزمة Postman لم يتغيرا: هذا
سلوك محلي للجهاز، وليس endpoint خلفيًا جديدًا.

نقر الخريطة يعرض اختيار الوجهة أو الانطلاق، مع وصف اختياري. عند غياب
reverse API تُحفظ النقطة الدقيقة بعنوان عام «نقطة على الخريطة» أو بالوصف
الذي كتبه المستخدم؛ لا تُخترع أسماء شوارع ولا تُستخدم fixtures لعكس العنوان.
خوادم OSM هنا للبلاطات فقط، ولم تُضف خدمة geocoding عامة أو endpoint جديدًا.
