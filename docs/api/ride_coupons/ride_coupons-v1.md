# كوبونات المشوار v1 — عقد مقترح

هذا تسليم للباكند، وليس خدمة موصولة. `base_url` ينتهي بـ`/api/v1`.
كل العمليات لحساب موثّق بـBearer وAccept:application/json؛ الضيف وlocalAccess ليسا توكنًا.

## GET /coupons
يرد `200 {data: Coupon[]}`؛ القائمة الخالية نجاح صحيح. كل عنصر يضم:
`code` محارف ASCII كبيرة بطول1–32، `percent` عدد صحيح1–100،
`is_available` bool، `expires_at` UTC ISO8601 أوnull،
`remaining_trips` و`total_trips` عددان صحيحان غير سالبين أوnull لغير المحدود.
إن وُجدا يجب أن remaining≤total. يمنع تكرار code.
الواجهة تعرض تلقائيًا المتاح وغير المنتهي وله استخدام متبقٍ، دون تطبيقه أو خصمه دون اختيار الراكب.
الخادم مسؤول عن أهلية الحساب؛ قائمة الكوبونات ليست تصريحًا باستخدامها على كل فئة أو مسار.

## POST /coupons/activate
جسم الطلب `{code:"TAM10"}` فقط. يطبّع الخادم الرمز(trim/uppercase)، ويتحقق من الأهلية
والانتهاء والحصة، ويضيفه للحساب، ويرد `200 {data:Coupon}`.
إعادة تفعيل الرمز نفسه عملية idempotent تعيد العنصر نفسه، ولا تستهلك رحلة أو ترصيد محفظة.
لا يقبل العميل percent أوexpiry كمدخل موثوق.
اختيار العنصر يرسل coupon_code إلى عقد [طلب الرحلة v2](../ride_request/ride_request-v2.md)
ويطلب تسعيرًا جديدًا؛ لا يُحسب خصم مالي حقيقي داخل الواجهة.
الحجز وحده يستهلك الاستحقاق ذريًا مع السعر والدفع حسب v2.

## الأخطاء والاتصال
401 UNAUTHENTICATED،403 FORBIDDEN،422 COUPON_INVALID أوVALIDATION_ERROR،
429 RATE_LIMITED،503 SERVICE_UNAVAILABLE؛ غلاف error يحوي code وmessage.ar/en.
فشل القائمة يعرض إعادة محاولة ولا يُفسّر كفراغ. فشل التفعيل لا يضيف عنصرًا ناجحًا محليًا
في API، وفشل التسعير يمنع التأكيد إلى أن يُصحح الرمز أو يُزال. لا fallback منAPI إلىMock.

## الربط الحالي
التطوير يعمل على MockCouponBook الموجود ضمن جلسة التطبيق؛ TAM10 هو الرمز الوحيد
الذي يقبله تسعير المحاكاة. NOW25 وSAVE15 أمثلة غير متاحة. حقول أمثلة JSON تطابق
DemoCoupon وRideCouponOffer؛ أمثلة TAM10 تمثل الحالة بعد التفعيل. هذه البيانات محلية
ولا تخص حملة حقيقية. تفعيل API/تحميل كتالوجه لم يُربط بعد؛ لا تدعي الواجهة نجاح HTTP.
