# تسليم كوبونات المشوار
اقرأ [عقد v1](ride_coupons-v1.md)، واستورد `ride_coupons-v1.postman_collection.json`.
توجد أمثلة JSON للمتاح والفراغ والتفعيل والخطأ في examples، ونفس المحتوى ضمن saved responses.
جرّب GET ثم POST code:TAM10 ثم GET، وتحقق من ثبات التفعيل المتكرر ومن إعادة تسعير الرحلة.
يلزم اختبار 401/403 والرمز المنتهي والحصة المستنفدة والاتصال وسباق الحجز على الخادم.
الحزمة اقتراح قابل للمراجعة؛ فُحص JSON محليًا، ولم يُنفذ استيرادGUI أو HTTP حي.
العميل الحالي Mock فقط لهذا الكتالوج؛ ملف التسليم لا يعني وجود باكند أو استعدادًا للإطلاق.
