## ما تغير

- SVG أصلية شفافة للموتور والفان، مع الإبقاء على رمز السيارة الموجود.96×160، مقدمة كل مركبة نحو الشمال؛ `currentColor` من الثيم. الرموز المرسومة فعليًا موجودة في car.png/motorbike.png/van.png، وملفات المصدر داخل assets/maps.
- اختيار الشكل من `trip.booking.vehicleClassId` عبر selector عرض واحد. motorbike→موتور، van→فان، standard/comfort وفئات السيارة المستقبلية→سيارة. fallback لرمز السيارة عند نوع غير معروف؛ لا استنتاج النوع من السعر أو اسم السائق.
- Native MapLibre يحمّل sprites الثلاثة مرة عند تركيب style، ثم يستعمل vehicle_icon في مصدر موقع السائق. تغيير النوع/الموقع لا يعيد بناء MapLibre أو الكاميرا/المسار. Raster والخرائط المضمنة والتتبع من الرابط المباشر تتلقى النوع والاتجاه الصحيحين أيضًا. لم يتغير مسار OSRM أو نموذج السعر.
- شارة الرحلة تعرض نوع المركبة، ومعلومات تعيين mock الجديدة/القديمة أثناء نشاطها تعرض موتور/فان بدل كيا ثابتة. معلومات سائق API لا يعاد كتابتها. الحجز والسائق لا يزالان محاكاة في هذا الوضع.
- نافذة السائق تفضل صورته الفعلية للمركبة، ومع غياب/فشل الصورة تستخدم SVG المناسب. صور العرض التجريبية للموتور والفان من الأصول الموجودة أصلًا. تغيرت الصياغة العربية إلى «المركبة» في عنوان التفاصيل ورقم اللوحة؛ English كان عامًا بالفعل. جرى sync_feature_l10n.py وflutter gen-l10n، والتعديلات المولدة محصورة بالمفتاحين.
- لا DTO/endpoints/حقول API جديدة؛ contract active_trip v1.1 يشرح استخدام vehicle_class_id الموجود.
