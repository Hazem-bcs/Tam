# AUI-10 — حركة السيارة ومحاكاة التتبع

Baseline b9cdc8a؛ أثناء العمل أضاف عميل آخر fa2a465 لإصلاح لوحة مفاتيح العناوين، وحُفظ كما هو. فرع ahmad-ui؛ لا push/main/CI.

## التنفيذ

- هندسة مسار اختيارية بحسب المرحلة واتجاه اختياري لكل fix في Domain وcodec ولقطات التخزين.
- الاستيفاء على طول polyline، واتجاه جغرافي متوافق مع دوران الخريطة في MapLibre وflutter_map، وتنعيم الزوايا على نافذة قصيرة حول المقطع. لا يتنبأ العرض بموقع لم يصل.
- إسقاط عرضي محدود على المسار القريب، تجاهل المواقع القديمة، تثبيت تذبذب أقل من 0.8م، ومزامنة مباشرة للقفزات/انقطاع التحديثات/تغير المسار. إخفاء السيارة عند تقادمها حسب الحالة الحالية. احترام تقليل الحركة والخلفية.
- مصدر GeoJSON منفصل للسيارة لتجنب إعادة إرسال خط كبير في كل إطار؛ العرض نحو 30 تحديثًا/ثانية كحد أقصى.
- محاكاة الاصطناعية من data/mock تنتج نفس snapshots التي يقبلها API codec. لا خدمات عامة جديدة، ولا محاكاة نجاح في وضع API. لا GPS حقيقي أو خدمة توجيه شوارع متصلة حاليًا.

## التحقق الفعلي

- مجموعة maps + active_trip + mock_trip_snapshot: 145 ناجحًا وواحد فشل بسبب تحديث مثال زاوية السيارة بعد تحسين نافذة الاتجاه. حُدّث المثال ونسخته في Postman، وأعيد ملف العقد المتأثر فقط: 5/5 ناجحة. بقية الاختبارات لم تتغير.
- اختبارات الحركة/الهندسة/native renderer الجديدة أو المحدثة نجحت، بما فيها استمرار نفس map/camera/sprites، قفزة التاريخ للوراء، توقف الحركة، تقليل الحركة، وتطابق mock مع codec. دورة الفحص السابقة تشمل 6 اختبارات geometry/motion/contract و10 regressions native.
- التحليل للملفات المعدّلة المعنية و3 ملفات اختبارات جديدة: لا ملاحظات، /tmp/tam-tracking-final-analyze.log.
- Format للملفات المملوكة وgit diff --check سليم.
- اختبار app/active_trip_integration_test.dart الأقدم لا يزال يفشل لأنه يفتح زر «تفاصيل الطلب» الذي حذفه المستخدم سابقًا؛ حالتا منع guest/localAccess في API نجحتا. لم ندّع نجاح المجموعة العامة؛ فحوص المشروع العامة مؤجلة لنقطة التكامل.
- Android emulator-5554: build/install/run ناجحة؛ طلب تجريبي من GPS إلى عنوان محفوظ، وصورة فعلية [الوصول للراكب](android-to-pickup.png). تبين المسار الاصطناعي والسيارة، وليس شبكة طرق حقيقية. Screenshot وحركة map فُحصا مع اختبارات الرسم الأصلية.

## التسليم للباك إند

[عقد الإضافة v1.1](../../../api/active_trip/tracking-v1.1.ar.md)، وثلاثة أمثلة الحالات الحالية ونسخها في Postman. المطلوب من الخادم عند الربط: موقع السائق بوقته ورقم revision واتجاهه إن توفر، وهندسة طريق صحيحة إلى الانطلاق/الوجهة من مزود routing، ثم transport آمن (polling الحالي أو realtime لاحقًا). مزود الخريطة لا يحسب طرق الشوارع تلقائيًا.

الحد الحالي: path المحاكاة اصطناعي ذو منعطفات وزمن مضغوط؛ لا ندّعي مراعاة الشوارع/اتجاه السير الفعلي أو مطابقة GPS الكاملة. ملف حركة السيارة 173 سطرًا تقريبًا ومفصول عن الحساب الجغرافي، لا تغييرات Auth أو أسعار.
