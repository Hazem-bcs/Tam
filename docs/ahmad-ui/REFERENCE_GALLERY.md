# Ahmad UI — معرض مراجع تصميم تطبيق العميل

> **مرجع بصري أصلي وليس صوراً من التطبيق المنفذ.** مصدر الصور هو `apps/customer/Tam Cusstomer UI/` من `main` عند `ffad266`. هذا المعرض يتضمن **14 مرجعاً للعميل** ويستبعد **10 مراجع تخص السائق**؛ لا يجوز استيراد عناصر السائق إلى تطبيق العميل.
>
> الاسم الظاهر للمستخدم هو **«تم / TAM»**؛ **Ahmad UI** اسم نسخة تصميم بديلة فقط.

الهدف: مكان واحد لتصفح الصور المطلوبة ثم مقارنة **المنفذ فعلياً** لاحقاً بلقطات Flutter الموجودة في [لوحة التقدم](README.md). اضغط على أي صورة لرؤيتها بالحجم الأصلي. بعض ملفات WhatsApp تضم أكثر من حالة أو شاشة؛ افحصها كاملة قبل البرمجة.

## الصور المستبعدة من نطاق تطبيق العميل

مراجع السائق **UI-14 وUI-16 إلى UI-24** محفوظة دون تعديل في المجلد الأصلي، لكنها ليست تكليفات للنسخة الحالية. يراجعها المشرف فقط عندما يقرر المستخدم بدء تصميم تطبيق السائق.

- **Reference:** ملفات WhatsApp أعلاه.
- **Implementation:** Flutter Widgets داخل `apps/customer/lib/features/` على فرع `ahmad-ui`.
- **Preview:** صور Flutter Golden/Android المرفوعة مع كل Pull Request، ولا تعني وحدها تحقق الأداء على جهاز فعلي.
- **Approved:** لا تُعلَم الشاشة كمكتملة إلا بعد تقييم المستخدم وقبول SHA محدد، مع اجتياز الاختبارات المناسبة.
