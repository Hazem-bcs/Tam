## خطا التصميم والإصدار

| النسخة | الفرع | ماذا يحدث؟ |
|---|---|---|
| **TAM Current** | `main` | نحتفظ بالتصميم الحالي ونواصل تطويره بصورة مستقلة. **ممنوع** إدخال تصميم أحمد فيه تلقائياً. |
| **TAM Ahmad UI** | `ahmad-ui` | فرع تصميم بديل بدأ بنسخة مطابقة لـ`main` عند `ffad266d4de544d7634bec79ac25587584987416`، ويحوي الآن تنفيذ الرئيسية قيد مراجعة المستخدم. |

**مهم:** لا تنتج الفروع وحدها تطبيقين يُثبَّتان معاً أو حزمتي إنتاج منفصلتين. عند مرحلة العرض النهائي نبني من كل فرع بصورة منفصلة ونميز أسماء APK وعينات الصور؛ إذا كانت نسختان دائمتان مطلوبة في منتج واحد نقرر تصميم Flutter flavors صراحةً.

## نقطة البداية المثبتة — 2026-11-17

التصميم الحالي محفوظ في `main` عند `746eb17`، بما فيه لوحة المركبات المدمجة بحد أقصى ثلثي الشاشة. جُهّز `ahmad-ui` محليًا من الفرع الموجود أصلًا، ثم جُمعت فيه أحدث نسخة main عند `bb4ff0c` مع الحفاظ على وثائق Ahmad UI. كود التطبيق في هذه النقطة مطابق لـmain؛ الفروق الحالية وثائق التصميم فقط. لا إعادة تصميم منفذة بعد، ولا تغييرات Ahmad UI تُدمج تلقائيًا إلىmain. يبقى Wave 0 ثم تكليف الشاشات وفق الخطة أعلاه نقطة بدء التنفيذ. لم يُجرَ push أو تشغيل CI أو اختبارات إضافية لهذه التهيئة.

## عملية التسليم السريعة

```text
main (التصميم الحالي — بدون تغيير)
  |
  +-- ahmad-ui (النسخة البديلة الوحيدة)
        |
        +-- ahmad-ui/home
        +-- ahmad-ui/auth
        +-- ahmad-ui/addresses
        +-- ahmad-ui/trips-list / trips-detail
        +-- ahmad-ui/ride-location / ride-schedule / ride-vehicle
        +-- ahmad-ui/active-trip / chat / notifications / settings
        |
        +-- PRs → Cloud Checks → Screenshots → Independent Review
        |
        +-- Approved SHAs → Ahmad integration → Android preview
```

- **Wave 0:** تجميد هوية Ahmad المشتركة، الـtokens والعناصر الأساسية، ثم تحديد SHA موحد لتكليف جميع واجهات الدفعة.
- **Wave 1:** تطوير الشاشات بشكل متوازٍ داخل ملكية الملفات، بلا تغيير `main`.
- **Wave 2:** عرض الصور الفعلية للمالك ومراجعة UX/RTL/LTR والتحليل والمخاطر.
- **Wave 3:** دمج الأعمال المعتمدة في `ahmad-ui` فقط، وفحص تكامل رحلة المستخدم.
- **Wave 4:** مقارنة حزمتَي TAM Current وTAM Ahmad UI جنباً إلى جنب، لاتخاذ قرار المدير.
